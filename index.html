💰 Live Monetization Guide
📘 Facebook Live
  1. Open OBS Studio → Settings → Stream → Service: Facebook Live
  2. Go to facebook.com/live/create → copy your Stream Key
  3. In OBS: add a Window Capture source → select this browser window
  4. Click Start Streaming in OBS, then Go Live on Facebook
  5. Enable Stars (Facebook's tip currency) in Creator Studio → Monetization
💡 Tip: Pin a comment: "Send ⭐ Stars if you got it right!" — viewers tap to tip.
▶️ YouTube Live
  1. Open YouTube Studio → Go Live → Stream (not webcam)
  2. Copy Stream key → paste into OBS Settings → Stream
  3. Add Window Capture in OBS → select this tab
  4. Start OBS stream → click Go Live in YouTube Studio
  5. Enable Super Chat & Super Thanks in YouTube Monetization settings
💡 Tip: Say aloud: "Super Chat your answer to get it read first!" every 3–4 puzzles.
📸 Instagram Live
  1. Instagram Live is mobile only — use screen mirroring
  2. Android: Use Scrcpy or Vysor to mirror your PC to phone, then record the screen to phone
  3. iPhone: Use QuickTime on Mac, or AirPlay + screen recording
  4. Open Instagram app → tap + → Live → start broadcast
  5. Enable Badges in Instagram Live — viewers buy badges (💗 £0.99–£4.99) to support you
💡 Tip: Say: "Send a badge if you solved it — I'll give you a shoutout!"
🚀 Engagement Rules (avoid spam filters)
  • Space CTAs at least 3 min apart — never every puzzle
  • Read viewer names aloud — builds connection (the host already does this!)
  • Ask open questions: "Who thinks it's 12? Who thinks 9?"
  • Post at peak hours: 7–9 PM local time for your audience
  • Use consistent schedule: same day/time every week
  • Add puzzle thumbnail as stream preview — boosts discovery clicks
